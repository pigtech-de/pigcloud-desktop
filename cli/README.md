# PigCloud CLI

Command-line access to PigCloud storage, sharing and local encryption.

## Commands

- Install on Linux/macOS: `curl -fsSL https://pigcloud.de/cli/install.sh | sh`
- Install on Windows: `winget install PigTech.PigCloudCLI`
- Build with the Go toolchain in `go.mod`: `make build`
- Sign in: `pc login`
- List commands: `pc hl`
- Command flags and examples: `pc hl <command>`
- Inspect this installation: `pc doctor`
